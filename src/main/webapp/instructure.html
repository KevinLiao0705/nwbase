Process Instructure (From root.html)

Trace result based on root.html, MySystem.js, Server.js, App.java, and HelloServlet.java.

1) Browser loads root.html

HTML loads core scripts: jQuery, GlobalRes.js, MySystem.js, Server.js, Block.js, and other UI modules.

Entry: root.html
→

2) onLoad() runs

Mouse tracking is attached to #rootBody, then sys.indexLoaded() is called.

Code path: root.html inline script

3) System bootstrap

sys.indexLoaded() sets root style and starts animation timer with ani.setTimer().

Code path: MySystem.indexLoaded()
→

4) Periodic UI lifecycle

Timer drives repaint/check loop, watches model updates, and maintains page state.

Code path: MySystem + Animate + Block

5) User action creates command JSON

Features like login/save build command payload with act, type, retOpts, and opts.

Code path: Server.serverLogin(), Server.saveStringToFile(), ...
→

6) AJAX call to backend

Server.callServer() sends POST JSON to /hello with application/json;charset=utf-8.

Code path: Server.callServer()

7) Embedded Tomcat receives request

App.java manually maps servlet name helloServlet to URL /hello using:

context.addServletMappingDecoded("/hello", "helloServlet")

Runtime server: Embedded Tomcat in App.main()

8) HelloServlet processes command

doPost() reads request body, parses JSON, validates type=command, then dispatches business logic via anaJo(...).

Code path: HelloServlet.doPost()

9) JSON response is returned

Servlet writes JSON response with status/message/retOpts back to browser.

Header: application/json;charset=utf-8

10) Frontend callback updates UI

serverBackOk() reads retOpts.responseType/responseAction and triggers dialogs, messages, callbacks, and view updates.

Code path: Server.serverBackOk()

HelloServlet act Branch Details

act = login

Validates systemName/userName/password, loads system/user/paraSet files, verifies account, and returns userSet + paraSet + webIp.

act = readFile

Reads file by opts.fileName (under web root) and returns opts.fileContent.

act = saveStringToFile

Writes opts.content to target file, supports paraSet path remap via systemName, refreshes para map when paraSet is updated.

act = writeImageFile

Parses image JSON payload (width/height/data), converts RGBA array, and writes PNG via ImageHandle.createBmpFile.

act = sonprg

Reserved sub-program branch (e.g., Ics). Current code keeps this path as placeholder/commented implementation.

act = zipDir

Zips a directory into target archive by calling Lib.zipDir(dirName, zipName).

act = copyFile

Checks source/destination state and overwrite policy, then copies file with Lib.copyFile.

act = testServerResponse

Simple connectivity/test branch; returns test response message with opts.

act = readFileNames

Reads file names in a directory by compare patterns and returns array string in opts.value.

act = loadUserParaMap

Loads user parameter map for specified user and stores result in global GB.userParaMap.

act = readFilexxx

Legacy read branch, reads file content and optionally sets outName in response opts.

act = deleteFilesInDir

Deletes specified file list under target directory and returns actually deleted names.

Important routing note: in this project runtime, backend endpoint is /hello (from App.java mapping). Calling /helloServlet may return 404 unless separately mapped by container scanning/config.
